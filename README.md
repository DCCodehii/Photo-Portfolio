Overview
A modern, responsive portfolio website for Norrisgraphy - a professional photography and videography service specializing in event photography, drone shots, videography, and graphic design. This website showcases their services, client testimonials, and provides a seamless booking experience.

Features
🎯 Fully Responsive Design - Works perfectly on all devices

📱 Mobile-First Approach - Optimized for mobile users

✨ Smooth Animations - CSS transitions and JavaScript effects

📞 Contact Form - Integrated with PHP Mailer for appointment booking

🗂️ Service Showcase - Interactive service cards with hover effects

⭐ Testimonials Section - Client reviews with elegant design

🚀 Fast Performance - Optimized images and minimal JavaScript
